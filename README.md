# Student Study Planner

Student Study Planner is an application designed to help university students organize their academic workload. Students often have assignments, exams, and deadlines spread across multiple platforms, which can make planning difficult. The app lets users upload course syllabi, automatically builds a personalized schedule, and sends reminders about upcoming deadlines. It also recommends study sessions based on assignment difficulty and available time. The goal is to reduce missed deadlines and help students save up to five hours each week.
